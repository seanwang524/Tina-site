# Tina 的小小世界 · 个人网站

一个纯静态的个人展示网站：只有一个 `index.html`、一个样式表、一个脚本，没有任何依赖，
双击就能在浏览器里打开，也能直接传到任何静态托管上。

---

## 一、先在本地看看

双击 `index.html` 即可。想边改边看，可以在本目录里执行：

    python -m http.server 8080

然后打开 http://localhost:8080

---

## 二、怎么把内容换成你自己的

全部内容都在 `index.html` 里，用记事本或 VS Code 打开，搜索关键词替换即可。

| 要改的东西 | 搜索这个词 | 说明 |
| --- | --- | --- |
| 名字 | `Tina` | 一共出现 6 次，全部替换成她的名字或小名 |
| 年龄年级 | `10 岁`、`四年级` | 首页的标签和正文里都有 |
| 一句话介绍 | `喜欢画画、弹钢琴` | 首页那段大段文字 |
| 关于我 | `我是 Tina，今年 10 岁` | 三小段自我介绍 |
| 四个小档案 | `最喜欢的颜色` | 颜色、书、拿手菜、理想 |
| 六张爱好卡 | `画画`、`钢琴` … | 每张卡有标题和一句描述 |
| 作品 | `《春天的花园》` | 见下面「放照片」 |
| 成长足迹 | `2022` … `2026` | 五个年份条目，可增可删 |
| 愿望清单 | `读完 50 本书` | 进度条改 `--pct:64%` 这个数字 |
| 邮箱 | `hello@example.com` | 换成真实邮箱，留言按钮才有用 |

配色：打开 `styles.css`，最上面的 `:root` 里有 `--coral`（主色）、`--lemon`（高亮）、
`--mint`、`--lav` 等，改一个颜色整个网站都会跟着变。

## 三、放照片

在网站根目录建一个 `images` 文件夹，按下面的名字放进去，**不需要改任何代码**：

- `images/me.jpg` —— 首页那张人像（建议竖版 4:5，宽度 800px 左右）
- `images/work-1.jpg` ~ `images/work-6.jpg` —— 六件作品的图片

没有放图片时，页面会自动显示好看的占位色块和图标，不会出现裂图。

> 上传前建议压缩一下（tinypng.com 之类），单张控制在 300KB 以内，手机上打开才快。

## 四、注册域名 + 上线（一步一步来）

> 域名注册需要**实名认证和付款**，这一步必须由你本人操作，我无法代办。
> 但网站已经做好了，买完域名直接上传就行。

### 方案 A：免费托管 + 自己买域名（推荐，免备案）

1. **买域名**：打开阿里云（wanwang.aliyun.com）或腾讯云（cloud.tencent.com）的域名注册页，
   输入想要的名字查是否可注册。常见价格：`.com` 约 60–80 元/年，`.cn` 约 30 元/年，
   `.top` / `.xyz` 首年常只要 9–20 元。买完要做**实名认证**（上传身份证，1–2 天通过）。
2. **上传网站**：注册 GitHub 账号 → 新建仓库 → 把本文件夹里的所有文件传上去 →
   仓库 Settings → Pages → Source 选 `main` 分支 → 得到 `用户名.github.io/仓库名` 的网址。
   （也可以用 Cloudflare Pages 或 Netlify，拖拽文件夹上传即可，速度在国内更好一些。）
3. **绑定域名**：在托管平台里添加自定义域名，平台会给你一条 CNAME 记录；
   回到域名控制台 → 解析 → 添加这条 CNAME，等 10 分钟到 2 小时生效。
4. **开 HTTPS**：GitHub Pages / Cloudflare 都能一键申请免费证书，勾上就行。

⚠️ 如果服务器放在**中国大陆**（阿里云 ECS、腾讯云 CVM 等），域名必须先做 **ICP 备案**，
流程大约 1–3 周，期间网站不能对外访问。放 GitHub Pages / Cloudflare 这类境外托管则不需要备案。

### 方案 B：国内主机（访问最快，但要备案）

买阿里云/腾讯云轻量应用服务器 → 备案（1–3 周）→ 用宝塔面板或直接 nginx 把文件放进网站目录 → 解析域名。

### 域名起名建议

个人网站的名字越短越好记，可以试这些组合（把拼音换成她的名字）：

- `duoduo.com` / `duoduo.cn`（两个字的名字基本被注册了，需要加点东西）
- `duoduo.fun` / `duoduo.art` / `duoduo.me` / `duoduo.top`
- `xiaoduoduo.cn` / `duoduo2026.com` / `hello-duoduo.com`

小提示：`.fun`、`.art`、`.me` 这类后缀便宜又有趣，很适合小朋友的个人站；
`.cn` 在国内认知度最高，但同样要实名。

## 五、给家长的一条隐私提醒

这个网站是公开的，任何人都能看到。建议**不要**放：

- 学校全名、班级、学号
- 具体生日、家庭住址、常去的补习班
- 能看出小区位置的照片（门牌、窗外地标）
- 孩子的身份证号、护照等信息

"北京 · 四年级"这种粒度是安全的。想更稳妥，可以把城市也去掉，只留"四年级"。
